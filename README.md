# Fake Job Posting Detection using Exploratory Data Analysis
Exploratory Data Analysis of Fake Job Postings dataset to identify patterns and indicators of fraudulent job listings using Python, Pandas, Seaborn and Plotly.

<h2>🚨 Fake Job Detection using Exploratory Data Analysis</h2>

**📌 Project Overview**

Online job portals have made job searching easier, but they have also increased the number of fraudulent job postings. Fake job listings often aim to collect personal information or scam job seekers.

This project performs Exploratory Data Analysis (EDA) on a dataset of job postings to identify patterns and indicators that help distinguish fraudulent jobs from legitimate ones.

The analysis focuses on understanding the structure of job listings and discovering data-driven insights that may signal suspicious job postings.

**🎯 Objectives**

Analyze job posting data to identify fraud patterns

Perform Exploratory Data Analysis (EDA)

Understand the relationship between job attributes and fraudulent listings

Visualize patterns using data visualization techniques

Generate insights that can help detect fake job postings

These visualizations highlight relationships between different job attributes and fraud patterns.

**🔍 Key Insights**

Some interesting findings from the analysis include:

✔ Fraudulent job postings often lack company logos

✔ Certain employment types appear more frequently in fraudulent listings

✔ Some job descriptions show unusual patterns or missing information

✔ Certain industries and experience levels may show higher fraud occurrences

✔ Salary information is sometimes missing or inconsistent in fake postings
